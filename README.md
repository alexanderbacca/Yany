# Yany

PWA de rutina de ejercicios en casa: calentamiento, circuito principal y enfriamiento, con temporizadores, sonido y anuncios de voz en español.

Construida con **React + TypeScript + Vite + Tailwind CSS** y desplegada en GitHub Pages.

## Características

- Calentamiento guiado, circuito de 7 ejercicios y enfriamiento
- Temporizadores con sonido y anuncios de voz en español
- Historial de sesiones y gráfico de progreso semanal
- Funciona sin conexión (PWA) y se puede instalar en el teléfono

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue

Cada push a `main` ejecuta el workflow de GitHub Actions que construye y despliega la app en GitHub Pages.
